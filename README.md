# Обнаружение аномалий в телеметрии малого космического аппарата

Проект посвящён анализу телеметрии малого космического аппарата и выявлению нештатных состояний с помощью методов машинного обучения.

В рамках исследования мы провели разведочный анализ данных, подготовили несколько наборов признаков, обучили гибридные модели Conv1D + LSTM и разработали автокодировщик для обнаружения аномалий. Отдельно исследовали влияние отбора признаков и генетической оптимизации гиперпараметров на качество моделей.

## Задачи проекта

- исследовать структуру и распределения телеметрических признаков;
- подготовить данные для бинарной классификации штатных и нештатных состояний;
- сравнить модели на полном и сокращённом наборах признаков;
- построить гибридную нейросетевую модель Conv1D + LSTM;
- разработать автокодировщик для поиска аномалий;
- оценить модели с учётом дисбаланса классов;
- исследовать применение генетического алгоритма для подбора гиперпараметров.

## Данные

В проекте использовались телеметрические данные малого космического аппарата: 2 679 наблюдений и 49 исходных признаков, включающих токи, напряжения и показания температурных датчиков. После преобразования целевой переменной около 88% наблюдений соответствовали штатному состоянию и около 12% — нештатному.

Исходные данные были предоставлены преподавателем только для выполнения проекта. Разрешение на их публичное распространение отсутствует, поэтому датасеты не включены в репозиторий. Ноутбук содержит код, сохранённые результаты вычислений и визуализации, однако его полный повторный запуск без исходных файлов невозможен.

## Подход

Работа включала следующие этапы:

1. Разведочный анализ, проверка пропусков, дубликатов, выбросов и дисбаланса классов.
2. Корреляционный анализ, оценка Mutual Information и конструирование новых признаков.
3. Формирование шести вариантов данных с разными наборами признаков и способами масштабирования.
4. Обучение и сравнение гибридных моделей Conv1D + LSTM.
5. Подбор гиперпараметров с помощью генетического алгоритма.
6. Обучение автокодировщика Conv1D + LSTM на штатных наблюдениях.
7. Подбор порога аномалии на валидационной выборке и итоговая оценка на тестовой выборке.

## Основные результаты

- лучший F1-score классификатора — **0,969**;
- лучшая сбалансированная точность (Balanced Accuracy) — **0,989**;
- в одном из экспериментов модель обнаружила все **65 аномалий** тестовой выборки;
- ROC AUC автокодировщика на полном наборе признаков — **0,997**;
- сокращение набора с 49 до 19 признаков улучшило F1-score классификации;
- полный набор из 49 признаков обеспечил более высокое качество ранжирования;
- генетическая оптимизация не дала значимого улучшения относительно исходной конфигурации.

Полученные результаты показывают, что сокращённый набор признаков лучше подходит для пороговой классификации, тогда как полный набор сохраняет больше информации для ранжирования объектов и обнаружения аномалий.
